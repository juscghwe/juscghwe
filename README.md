👋 Hi, I'm Julian (@juscghwe)

I'm a hobby developer who enjoys figuring out how things work, from networking and Linux servers to the software running on top of them.

Most of what I know comes from tinkering with my homelab, breaking things, fixing them and occasionally thinking there's probably a better way to do something.

I'm not tied to a particular language or framework. I mostly care about understanding how the pieces fit together and making things a little easier to run and maintain without bypassing existing and well-intended boundaries.

🔧 What I'm tinkering with

- "Homelab Manager" (https://github.com/juscghwe/homelab-manager) - An experiment in decentralized management of Linux hosts, Docker deployments and network configurations through Git. Still early days.
- "PillTracker" (https://github.com/juscghwe/pilltracker) - A self-hosted medication tracker I'm building while learning more about full-stack development in the js / sql frameworks.
- "Caddy UI" (https://github.com/zackwag/caddy-ui) - Contributing feats, fixes, documentation, localization and testing improvements to a project I use myself.

🧩 Things I find interesting

Self-hosting, networking, Linux, automation, open source and the occasional rabbit hole with the invitating door sign of "surely this can't be that complicated". 

Mostly here to learn, build useful things and hopefully contribute something back along the way.
